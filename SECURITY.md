# Sécurité

Merci de **ne pas** signaler une faille de sécurité dans un ticket public.

Utilisez le signalement privé de GitHub : onglet **Security** du dépôt → **Report a vulnerability**.
Décrivez la faille, la version concernée et, si possible, comment la reproduire. Vous recevrez une
réponse sous quelques jours ; la correction est publiée dans une nouvelle version, puis la faille
est rendue publique avec votre accord, en vous créditant si vous le souhaitez.

Seule la dernière version publiée reçoit des correctifs de sécurité.

*English: please report vulnerabilities privately through GitHub's "Report a vulnerability" button
in the Security tab, not in a public issue.*
