# AquasManager

Suivi public d'AquasManager, l'application de gestion d'aquarium récifal et d'eau douce.

Ici, on discute des **idées de fonctionnalités** et des **problèmes rencontrés**.
Le code de l'application n'est pas publié dans ce dépôt.

## Proposer une idée

- **Depuis l'application** : menu utilisateur → « Proposer une idée ».
  Aucun compte GitHub n'est nécessaire.
- **Ou ici**, avec un compte GitHub : ouvre une issue.

Chaque idée est lue et discutée avant d'être éventuellement développée.
